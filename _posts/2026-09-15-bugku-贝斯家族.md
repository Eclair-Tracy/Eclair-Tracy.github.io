# Bugku CTF 贝斯家族 Writeup

## 题目描述

题目名称为贝斯家族，给出密文：@<,{bdR2Hj6*Tm,Wx2izpx2}。题目暗示属于 Base 系列编码类题型。

## 解题思路

题目名称“贝斯”谐音 Base，可直接判断本题为 Base 家族编码解密题。
观察密文特征：字符串< , { *` 等大量特殊符号。

结合 Base 编码特征快速排除：

1. Base16(Hex) 只有 0-9、a-f，无特殊符号，排除；

2. Base32 仅大写字母和少量数字，无特殊符号，排除；

3. Base64 不包含 < { , * 这类符号，排除；

4. 密文含大量特殊标点、无 = 填充符，完全符合 Base91 编码特征。

因此确定本题使用 Base91 编码解密。

## 解题步骤

1. 复制题目给出的密文 @iH<,{bdR2Hj6*Tm,Wx2izpx2}；

2. 使用 Base91 在线解密工具，直接粘贴密文解密；

3. 也可使用 Python 安装 base91 库，本地脚本解码；

4. 解码成功后直接得到标准格式 flag。

本题考察 CTF 常见 Base 家族编码区分，核心考点是通过字符集特征区分 Base64、Base32、Base91。Base91 支持大量特殊符号，是区别于其他 Base 编码的最明显特征。
