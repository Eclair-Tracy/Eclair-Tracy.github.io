# Bugku CTF - Morse Writeup
## 题目描述
题目描述中给出一串由`.`和`-`组成的字符串，使用斜杠`/`分隔不同字符，需要解码得到flag。

## 解题思路
本题考察<u>摩尔斯电码（Morse Code）</u>。字符串全部由点（`.`）和划（`-`）组成，且用`/`分隔，符合摩尔斯电码的编码格式。使用在线摩尔斯电码解码工具，将字符串粘贴解码即可得到flag。

## 解题步骤
1. 复制题目描述中的全部摩尔斯电码字符串。
2. 打开在线摩尔斯电码解码网站（如 Morse Code 在线翻译工具）。
3. 将字符串粘贴到输入框，选择"摩尔斯电码转文本"。
4. 解码得到文本，转换为小写格式，即为flag。

> 知识点：<u>摩尔斯电码</u>通过点（`.`）和划（`-`）的不同组合表示字母、数字和符号，是早期无线电通信的编码方式；CTF中常见的加密/编码题型。
