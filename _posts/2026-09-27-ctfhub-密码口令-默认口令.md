## 解题思路

本关卡的核心考点在于模拟真实世界中“管理员未修改设备出厂默认密码”的安全隐患。
解题流程为：访问靶场 -> 识别系统指纹 -> 搜索引擎查找默认凭证 -> 使用默认账号密码登录获取Flag。

##操作步骤

1. 开启靶场与系统识别

点击“启动环境”，访问分配到的 URL。页面加载后，发现是一个邮件系统的登录页面。
通过查看网页底部的 Copyright 信息或 URL 特征（login.php），可以识别出该系统是亿邮（eYou）邮件网关系统。

2. 信息搜集与默认凭证查找

既然明确了系统类型，第一反应不应该是盲目爆破，而是利用公开情报（OSINT）寻找厂商预置的默认口令。
在搜索引擎（如百度、Google）中搜索关键词：亿邮 邮件网关 默认密码 或 eyou mail gateway default credentials。

整理网络上公开的默认账户密码组合如下（最常用的核心组合已加粗）：

· eyougw / admin@(eyou) 
· admin / +-ccccc
· admin / cyouadmin
· eyouuser / eyou_admin
· eyouadmin / aaaaa

3. 尝试登录与踩坑记录

在登录框依次输入默认凭证进行尝试。

· 踩坑1（captcha error）：由于沙盒环境不稳定或页面会话（Session）刷新，第一次提交时提示验证码错误。解决方法：按 F5 强制刷新页面，仔细区分验证码大小写后重新输入。若依然报错，需等待片刻或重启靶场环境。
· 踩坑2（user is not exists）：输入某个错误组合后，页面提示“用户不存在”。这说明该系统下没有当前输入的用户名。解决方法：报错“用户不存在”说明该换用户名了；报错“密码错误”说明用户名是对的，该换密码了。于是换用 eyougw / admin@(eyou) 再次尝试。
· 成功登录：输入用户名 eyougw 和密码 admin@(eyou)，正确填写验证码后，点击登录，成功进入系统后台，并在后台首页或系统信息页面直接找到了 Flag{...}。
